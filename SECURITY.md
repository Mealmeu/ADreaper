# Security Policy

## Reporting a vulnerability in ADreaper

If you find a security issue **in ADreaper itself** (e.g. a code-execution bug
in the framework, a dependency vulnerability, or a way the tool could harm the
operator's own machine), please report it privately:

- Open a [GitHub Security Advisory](https://docs.github.com/en/code-security/security-advisories)
  on this repository, **or**
- Email the maintainers (see repository profile).

Please do not open a public issue for an undisclosed vulnerability. We aim to
acknowledge reports within a few days.

## Scope

This policy is about the security of the ADreaper codebase and its release
artifacts. It is **not** a channel for third-party findings you produced *using*
ADreaper — take those to the affected vendor's own disclosure process.

## Responsible use

ADreaper is an offensive-security assessment tool for **authorized** testing
only. Using it against systems you do not own or lack written permission to test
is outside the scope of this project and may be illegal. See
[DISCLAIMER.md](DISCLAIMER.md).
